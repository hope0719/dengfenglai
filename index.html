写作的决定权，在你手里。

打开，不等于发送给 AI

打开编辑器不会自动评估或润色。AI 功能需要你先配置服务、了解数据发送范围，再明确点击。

保存，不等于公开发布

草稿先保存在当前浏览器。只有你确认提交后，帖子才会发送到所选星球，按平台的可见范围展示。

连接，也可以随时清除

你可以在插件设置中清除连接配置。要撤销平台侧的密钥，还需要在对应服务的管理页面操作。

插件作者会收到我的草稿和 API Key 吗？

当前版本没有开发者数据中转服务器或统计服务。凭据保存在扩展本地，网络请求由插件直接发送至你使用的知识星球与硅基流动等服务。你主动提交给支持渠道的信息除外。

浏览这份官网，会调用 AI 或访问我的星球吗？

不会。本站是静态说明页面，没有账号登录、API Key 表单、AI调用或星球访问功能。托管方 GitHub 可能按其政策处理网站访问日志。

卸载插件，会删除已经发出的帖子吗？

不会。卸载只移除插件的浏览器本地存储。已发布帖子、已上传图片及第三方服务中的记录，需要分别通过对应平台管理。
