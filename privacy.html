01 · 适用范围与维护者

「等风来」是独立浏览器扩展，帮助用户将正在浏览的线索整理成图文草稿，并在确认后发布到知识星球。AI 评估和润色属于该写帖流程的一部分。

本产品及网站由 GitHub 账号 hope0719 维护。本文中“我们”指等风来的维护者。产品与知识星球、硅基流动以及界面中展示的社群无官方隶属关系。

第三方服务分别依其政策处理收到的数据。本政策说明插件自身的行为，不代替第三方政策，也不承诺第三方不保留数据或不将数据用于其他用途。

02 · 处理哪些数据，为什么使用

数据类别内容与来源用途与处理位置
所选页面内容用户打开写帖框时读取的原文、作者、标题、来源链接和图片引用。用于呈现来源和初始化草稿，保存在当前浏览器。仅在支持的网站提供入口，不读取无关网站或完整浏览历史。
草稿与附件用户输入的正文、选择或粘贴的图片、标签和目标星球。用于本地编辑和保存；点击 AI 功能时发送所需材料，确认发布时提交确认稿及所选图片。
连接与认证信息用户填写的知识星球 MCP 链接（含 API Key）、硅基流动 API Key，以及选择的模型。保存在扩展本地配置，分别发送至对应服务进行认证；不使用 Chrome 云同步，不提供给网页内容脚本。
账号与星球信息知识星球返回的账号标识、名称、加入的星球、标签和必要权限信息。用于显示账号、限制可选目标、准备发布及隔离不同账号的提交记录；部分信息在运行期间临时处理。
发布记录提交标识、账号标识、目标星球、请求摘要、确认稿、图片编号、帖子编号、时间和提交状态。保存在浏览器本地，用于避免重复提交、恢复状态和隔离账号。不作为行为分析或广告画像。

插件不读取浏览器登录 Cookie，不索取知识星球账号密码，不收集无关网站的浏览历史。插件不会因你只是打开编辑器，就自动发送稿件给 AI。

03 · 数据发送给哪些第三方

接收方触发方式与目的可能发送的数据
知识星球
mcp.zsxq.com		连接测试或编辑器检查连接时读取账号与星球；发布时获取标签、上传凭证并创建主题。MCP 认证信息、必要接口参数；确认发布后的正文、标签、图片编号及目标星球。
七牛图片上传服务
up-z1.qiniup.com		在确认发布且包含图片时，使用知识星球提供的凭证上传。所选图片二进制、图片元数据及短期上传凭证。上传结果由服务商回调知识星球。
硅基流动
api.siliconflow.cn		连接测试读取模型列表；在已同意 AI 数据发送且点击评估或润色时进行推理。API Key、模型、必要提示词，以及对应的原文、草稿、作者信息、所附图片和调用参数。
原站图片服务用户选择添加原帖配图时下载该图片。所选图片地址及网络请求元数据。支持的域名包括 pbs.twimg.com、mmbiz.qpic.cn、i.redd.it、preview.redd.it 和 external-preview.redd.it。

网络服务在接收请求时还可能获得 IP 地址、时间、请求大小及服务运行所需的技术信息。用户选择的服务和网络路径可能涉及不同地区；请在发送内容前查看对应服务的数据处理规则。

第三方政策：知识星球隐私政策、硅基流动隐私政策、七牛隐私政策。已发布内容的访问范围由目标星球及知识星球的规则决定。

04 · 用户控制与同意

  • 填写连接配置前，可以先阅读本政策与插件内的数据使用说明。
  • AI 功能要求在设置中了解并勾选数据发送说明；只有明确点击评估或润色后才发送相应材料。你可以取消勾选以停止后续 AI 调用。
  • 是否附上来源链接、添加哪些图片、选择哪些目标及标签，由你在编辑器中决定。
  • 只有确认发布后才会提交创建请求。响应不确定时不自动重发，也不要求读取星球主题列表才能发布。
  • 你可以只使用本地草稿编辑功能，不调用 AI 或发布接口。

05 · 保存时间与删除方式

草稿、图片、配置和提交记录保存在当前浏览器的扩展存储中，当前版本没有统一的定期清理周期，通常保留至你移除相关数据、清除扩展存储或卸载扩展。浏览器自身的清理、配额和配置也可能影响存储。

  • 清除连接配置：在插件设置中点击“清除连接配置”。这会移除本地保存的连接与密钥配置，但保留草稿。
  • 撤销平台权限：在知识星球密钥管理页和硅基流动控制台撤销或更换对应密钥。本地清除配置不等于服务端撤销。
  • 删除本地数据：可清除扩展存储或卸载扩展。卸载前请自行保存需要保留的稿件。
  • 管理已发内容：已经提交的帖子和图片不会因清除配置或卸载而删除，需要通过知识星球及相关服务管理。
  • 第三方留存：已发送的 AI 材料、上传文件和服务日志由对应服务按其规则保存和处理，我们不能通过删除本地数据将其一并删除。

06 · 安全措施与边界

扩展使用 HTTPS 与指定服务通信，限制网络目标范围，并在后台处理凭据。凭据不写入发布的安装包，不通过插件自有日志输出，不使用浏览器云同步，也不向内容脚本返回明文配置。

浏览器本地存储不等同于系统钥匙串，也不是对本机所有软件都不可读取的加密保险箱。请保护设备、浏览器账号和备份，不在公开截图、反馈或聊天中分享 API Key、MCP 链接或上传凭证。

本产品不要求提供验证码、支付密码、身份证件或系统权限。我们不会要求你为提交反馈而交出平台密钥。

07 · 数据使用限制

我们仅将插件处理的数据用于已披露的写帖、AI辅助、发布、认证和必要的状态恢复功能，不出售用户数据，不用于个性化广告、数据经纪业务或信用评估，不建立浏览行为画像，也不使用用户稿件训练开发者自己的模型。

等风来对通过 Chrome 扩展获得的用户数据的使用遵守 Chrome Web Store 用户数据政策，包括 Limited Use 限制。我们不设置开发者内容审阅后台；你主动通过支持渠道提供的反馈，会仅为处理该问题而使用。第三方服务的独立处理规则以其政策及你与该服务的约定为准。

08 · 本网站访问与支持数据

本网站是 GitHub Pages 托管的静态说明页面，没有账号登录、密钥表单、广告、分析脚本、自有追踪 Cookie 或插件业务接口。仅访问本网站不会调用 AI、读取浏览器草稿或访问你的星球。

GitHub 及其基础设施可能为托管、安全和服务运行处理 IP 地址、浏览器信息及请求日志，相关规则见 GitHub 隐私声明。访问外部链接后，适用对应服务的政策。

你主动通过 GitHub Issues 提交的反馈会在 GitHub 公开显示，并由 GitHub 处理账号及提交信息。请不要提交密钥、私人稿件或其他敏感信息。

本工具不面向未满 14 周岁的儿童提供专门服务，也不主动索取年龄或儿童信息。如果你认为支持渠道中出现了不应公开的未成年人信息，请及时联系我们。
