Help & support

把连接配好，把决定留给自己。

这里提供使用指引和联系入口，不接收你的平台密钥。

开始使用

  1. 在 Chrome 中打开已安装的等风来扩展设置页。
  2. 从知识星球官方密钥管理页点击“查看密钥”并复制 API Key，粘贴到插件设置中；原有 MCP 链接也可以继续使用。
  3. 填写自己的硅基流动 API Key 和可用模型。两个密钥输入框均可点击“显示／隐藏”，也可按需查看已保存的密钥。没有账号时，可点击注册硅基流动。该链接包含邀请标识，是否使用由你决定。
  4. 阅读并选择是否同意 AI 数据发送，保存后测试连接。AI费用由对应服务账户计收。
  5. 刷新 X、Reddit 或 Chrome 中的公众号文章，在原文旁点击“发到星球”开始写稿。

当前版本提供生财有术、AI破局和玩赚新媒三个预设目标。需要你已加入目标星球，并有相应发帖权限。公众号入口仅指 Chrome 网页，不包含微信电脑版内部入口。

管理你的数据

取消设置中的 AI 数据发送勾选，可以停止后续 AI 调用；点击“清除连接配置”，可以移除插件本地保存的连接和密钥。若要撤销平台侧访问权限，还需前往知识星球或硅基流动的密钥管理页面操作。

清除配置会保留草稿。清除扩展存储或卸载可以移除本地保存的数据。已经发送给平台的内容，需通过对应平台管理。完整范围见隐私政策。

提交反馈或隐私问题

维护者为 GitHub 用户 hope0719。你可以在项目中描述问题，提供插件版本、操作步骤及经过脱敏的错误提示。

GitHub Issues 是公开渠道。不要提交 API Key、含密钥的 MCP 链接、验证码、私人稿件或未脱敏的账号截图。涉及敏感信息时，先只说明问题类型，并提出私密沟通需求。
