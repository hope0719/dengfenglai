# 等风来 · 隐私与支持网站

等风来浏览器扩展的公开隐私政策与支持页面。纯 HTML/CSS 静态站，无构建依赖，无表单、分析脚本或开发者业务接口。

- 首页：`index.html`
- 隐私政策：`privacy.html`
- 使用与支持：`support.html`
- 样式与图标：`styles.css`、`assets/logo.svg`

部署使用 GitHub Pages，来源为 `main` 分支根目录。`.nojekyll` 禁用 Jekyll 处理。静态站无需服务器运行环境；本地可临时用任意静态文件服务器预览。

本仓库仅包含网站公开文件，不包含插件凭据、用户草稿、发布记录或插件安装包。

维护者：[@hope0719](https://github.com/hope0719)。支持入口：[Issues](https://github.com/hope0719/dengfenglai/issues)。公开反馈请勿提交密钥或个人敏感信息。
